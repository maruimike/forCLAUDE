# ANA / JAL マイルの実質購買力（RPP）分析

航空マイルの「1マイル＝○円」という換算が、正規運賃（普通運賃・正規ビジネス運賃）を分子に置いた
**見せかけの換算価値**になっている問題を排除し、合理的な消費者が現金で同じ役務を調達する場合の
**実質購買力（Real Purchasing Power, RPP）** を定量的に算出・検証するリポジトリです。

```
RPP [円/マイル] = p × v(特典枠あり) + (1 − p) × v(特典枠なし)
v(経路) = ( V_real − 現金支払 ) / 消費マイル      ※マイルを使わない経路では v = r_alt（未使用マイルの代替価値）
```

| 記号 | 意味 |
|---|---|
| `V_real` | 同区間・同等シートを現金で調達する場合の **現実的な代替最安価格**（往復・税込）。プロファイル N は早割・LCC（手数料・荷物・アクセス差込み）・新幹線・ZIPAIR・外資系セールの最安値、プロファイル S は同一会社（ANA/JAL）の有償運賃 |
| `C_cash` | 特典航空券の発券時に **別途現金で徴収される費用**（燃油サーチャージ・空港施設使用料・諸税） |
| `p` | 基本枠（ANA：特典枠、JAL：基本マイル枠）が取れる確率（需要帯別の事前分布） |
| 経路 | 特典（基本マイル＋C）／JAL 特典航空券PLUS（k×基本マイル、上限あり、＋C）／コイン・ポイントで同一会社の有償運賃を購入（V_own ÷ r_coin マイル）／現金で払いマイルを温存（v = r_alt）。旅行者は「現金＋マイル×r_alt」が最小の経路を選ぶ |
| `r_alt` | 未使用マイルの代替価値。N：現金類似交換（0.8円）、S：ANA SKY コイン 1.2円／e JALポイント 1.5円 |

`rpp_award = (V_real − C_cash) / M_base` は「特典枠が取れて使った場合」の単純値で、2026年の燃油水準では国際線エコノミーで負になるケースがある。

## リポジトリ構成

```
data/params/            モデルの入力パラメータ（CSV、出典IDつき）
data/observations/      JAL 特典航空券PLUS 倍率などの観測データ
data/sources.csv        出典一覧
src/rpp_model/          モデル本体（識別式・モンテカルロ・感応度・作図）
src/run_analysis.py     一括実行スクリプト
output/tables/          計算結果（CSV）
output/figures/         図（PNG）
output/model_digest.md  計算結果の自動ダイジェスト
reports/                最終レポート（日本語）
research_notes/         リサーチノート（出典つき一次情報の整理）
```

## 実行方法

```bash
pip install -r requirements.txt
python3 src/run_analysis.py            # data/params を読み、output/ に表と図を出力
python3 src/run_analysis.py --n 50000  # モンテカルロの試行回数を変更
```

## 需要帯（demand band）

| ID | 需要帯 | 定義 |
|---|---|---|
| D1 | 閑散平日昼 | 火曜・水曜の 10〜16 時発、閑散期 |
| D2 | 通常 | 通常期の平日、朝夕ピーク以外 |
| D3 | 高需要時間帯 | 金曜 18〜20 時発、月曜 7〜8 時発、日曜夕方発 |
| D4 | 繁忙期 | 3 連休・年末年始・GW・お盆 |

ANA のシーズン制（L/R/H）、JAL の特典航空券PLUS 倍率、特典枠の空席確率、現金運賃はすべてこの需要帯ごとに
パラメータ化されています。

## 消費者プロファイル

| ID | プロファイル | 代替価格 V_real | 未使用マイルの価値 r_alt |
|---|---|---|---|
| N | 最安追求 | LCC・他社・新幹線・ZIPAIR・外資系セールを含む最安（準同等 near まで許容） | 現金類似交換 0.8 円 |
| S | 同一会社利用 | ANA/JAL の同一商品の有償運賃 | ANA SKY コイン 1.2 円／e JAL ポイント 1.5 円 |

レポート本文は `reports/ANA JAL マイル実質購買力分析.md`、計算結果の全表は `output/model_digest.md` を参照。
