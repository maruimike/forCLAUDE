# ANA（全日空）国内線特典航空券の制度と必要マイル数（基準日：2026年11月4日）

## 調査メモ（情報取得上の制約と確度の読み方）

- 本セッションでは www.ana.co.jp / www.anahd.co.jp および第三者サイト（Aviation Wire、Traicy、トラベルボイス、各マイル系ブログ、Wikipedia）への直接アクセスが、セッションのネットワーク制限（プロキシCONNECT 403 / ENOTFOUND）によりすべて不可だった。公式ページの記述は、Web検索ツールが返した要約・スニペット経由でのみ取得した。さらに途中で当該ターンのWeb検索回数上限（200回／ターン、全エージェント共有）に到達し、追加検索ができなくなった。
- したがって「出典URL」は検索結果で特定した公式／報道ページを示すが、本文の全文照合はできていない。各数値の確度を次の記号で示す。
  - **A**：公式ページ（ana.co.jp / anahd.co.jp）のスニペット・要約で直接確認した数値。
  - **B**：複数の第三者情報源（報道・ブログ）で一致、または公式スニペットと矛盾しない数値。
  - **C**：**推定**（調査者の既存知識に基づき、本調査では裏取りできなかった値）。モデル投入前に公式ページで必ず検証すること。
- 取得日（検索実施日）はすべて 2026-11-04。掲載日は判明分のみ記載。
- 「普通運賃」は価値基準として扱っていない（本メモでは記録もしていない）。
- クラス表記：2026-05-19搭乗分から公式表記が「普通席」→「エコノミークラス」、「プレミアムクラス」→「ファーストクラス（プレミアムクラス）」に変更された（出典はQ3参照）。本メモでは「エコノミー（旧・普通席）」と表記する。
- 後工程のモデル（src/rpp_model/model.py の award_miles.csv / award_cash_costs.csv / floor_rates.csv）に合わせ、表の列は route_id（IATAペア）、cabin、basis（OW/RT）、season（L/R/H）、miles、amount_jpy を意識して揃えた。

## Q1. 現行の国内線特典航空券の必要マイル数（片道）：区間距離帯×シーズン

### Takeaway
ANA国内線特典航空券の必要マイルは、2024-10-27搭乗分から適用の「区間マイル距離帯（4帯）×シーズン（L/R/H）」の固定チャートで決まり、片道1区間あたり最低6,000マイル（0〜300マイル区間・ローシーズン）〜最高13,000マイル（1,001〜2,000マイル区間・ハイシーズン）。2026-05-19の国内線リニューアル後も直行便1区間のマイル数は据え置きで、変動制（空席連動）は導入されていない。

### Inferences
- ANA公式が暗示する「1マイル＝1.0〜1.7円」は特典枠の有無に関係なく実現できる下限値（floor）であり、モデルの M_effective のフォールバック経路（特典枠が取れない場合にSKYコインで同じ便の有償運賃を買う）の換算レートとして使える。代表的会員像別には：一般会員1.2、ANAカード一般1.5（50,000マイル以上）、SFC／ゴールド1.6、上級会員1.7。
- 特典航空券の実効価値は、同一便の割引運賃（現金代替価格）÷（必要マイル）−（PFC現金分）で求まり、SKYコイン経路の1.0〜1.7円を下回る場合は特典を使わずコイン化する方が合理的。例：HND-OKA R期往復19,000マイル＋PFC1,640円に対し、同便の割引運賃往復が30,000円なら実効 (30,000−1,640)/19,000 ≈ 1.49円/マイルで、SFC保有者の1.6円フロアを下回る。
- SKYコインの有効期限（12か月）は交換タイミングのリスクを生むが、換算レートには影響しない。
